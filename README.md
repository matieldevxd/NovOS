# 🚀 NovOS

Sistema operativo experimental creado por Mati.

## 🧠 ¿Qué es NovOS?

NovOS es un proyecto que simula un sistema operativo para PC y dispositivos móviles, enfocado en ser ligero, creativo y accesible para todos.

## ⚙️ Características

* Interfaz tipo sistema operativo
* Apps integradas (Cámara, Google, juegos, etc.)
* Configuración del sistema
* Diseño optimizado para dispositivos modestos
* Proyecto en constante evolución

## 📱 Plataformas

* 💻 PC
* 📱 Mobile (adaptación de FlowOS)

## 🔓 Open Source
